# Bounce

Bounce is a company surfaced as a portfolio company of a16z, accel, general-catalyst and added to the API Evangelist network as a stub for enrichment. This profile is a lead awaiting the enrichment pipeline.

Bounce operates the world's largest luggage storage network — 32,000+ partner locations across 4,000+ cities — connecting travelers with local shops and hotels where they can securely store bags by the hour or day. Founded by Cody Candee in 2018.
